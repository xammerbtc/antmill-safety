# Contributing

Corrections, clearer wording, and new educational notes are welcome.

- Keep the tone calm and precise. This is education, not marketing.
- Do not promise returns, investment results, or guaranteed safety.
- If you mention AUROX, call it **planned**. It is not live.
- Do not add coin tickers, launch links, or pump.fun material.
- Do not include exploit payloads, working attack procedures, or copy-pasteable abuse against any system.
- Never commit secrets, keys, tokens, `.env` files, or wallet data.
- Write in English. Keep pull requests focused on one change.

Open a pull request against `main` and briefly explain the improvement.
