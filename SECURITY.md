# Security policy

If you believe you have found a vulnerability in AntMill, the Colony Mini App, the Telegram helper, or this documentation, please report it privately.

## How to report

- Prefer GitHub's private vulnerability reporting on this repository, once it is enabled.
- Or message the project through [@antmill_poster_bot](https://t.me/antmill_poster_bot) and say you need to reach the team about a security issue. Do not include secrets, seed phrases, or private keys in the first message.

Please give us a reasonable window to investigate before any public disclosure.

## Please do not

- Open a public issue that describes a working exploit.
- Include seed phrases, private keys, session tokens, or wallet recovery data in any report.
- Ask us to test a live drain, a stolen account, or a third-party system you do not own.
